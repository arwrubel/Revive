About Revive

Revive converts legacy educational PDFs — especially DLPT (Defense Language Proficiency Test) materials — into modern, interactive HTML quizzes that work offline.

Features

  • AI-powered question extraction from PDFs (via Claude API)
  • Bilingual Russian/English support with proper Cyrillic punctuation
  • Audio listening comprehension with configurable play limits
  • DLPT-style transcript reveal (only after answering)
  • 100% standalone HTML output — works offline, no dependencies
  • Manual quiz builder for creating questions without a PDF

How It Works

  1. Upload a PDF (requires backend) or add questions manually
  2. Review and edit questions in the builder
  3. Generate a standalone HTML quiz file
  4. Download and share — it works anywhere, offline

Russian Punctuation

When processing Russian text, these rules are applied automatically:

  • Guillemets «» for all quotations (not "" or "")
  • Em-dashes — for dialogue and ranges (not hyphens)
  • Commas before subordinating conjunctions (что, который, где, когда, etc.)
